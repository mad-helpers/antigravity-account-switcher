# Legacy ChatGPT Desktop & Codex Companion Modules

These standalone Codex / ChatGPT Desktop utilities were moved out of the root directory in Antigravity Account Switcher v3.0 to keep the primary package focused and modular:

- `chatgpt_account_manager.py` — Multi-profile `auth.json` switcher and isolated dual-window launcher for Codex / ChatGPT Desktop.
- `chatgpt_cdp_daemon.py` — Chrome DevTools Protocol theme/font/RTL injector daemon for ChatGPT Desktop ports `9223`/`9224`.
